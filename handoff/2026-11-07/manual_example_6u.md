## 1. 单元设定

单元数量取 6，人口取整百，合计 2100 —— 目的是让每一步都能在纸上核对。

| zone_id | pop | a_i（每千人桩数） | 基准半径内有站 | 说明 |
|---|---|---|---|---|
| Z1 | 100 | 0 | 否 | 无观测覆盖，同时必然是最低可达 |
| Z2 | 200 | 2 | 是 | 恰好落在 20% 分位阈值上 |
| Z3 | 300 | 4 | 是 | |
| Z4 | 400 | 6 | 是 | |
| Z5 | 500 | 8 | 是 | |
| Z6 | 600 | 10 | 是 | |
| 合计 | **2100** | — | — | |

`a_i` 的单位是**桩/人 × 1000**，即「每千人桩数」。计划 §4.1 明令不得写「车桩比」。

## 2. 加权均值（手算）

```
ΣP  = 100 + 200 + 300 + 400 + 500 + 600 = 2100
ΣPa = 100×0 + 200×2 + 300×4 + 400×6 + 500×8 + 600×10
    = 0 + 400 + 1200 + 2400 + 4000 + 6000 = 14000
加权均值 ā = 14000 / 2100 = 6.666667
```

---

## 3. 人口加权 Gini（手算）

公式（§4.3）：`G = ΣΣ w_i w_j |a_i − a_j| / (2 · ā · (Σw)²)`，其中 `w = P`。

因为 `ā = ΣPa / ΣP`，分母可以化简成一个整数：

```
分母 = 2 · ā · (ΣP)² = 2 · (ΣPa/ΣP) · (ΣP)² = 2 · ΣPa · ΣP = 2 × 14000 × 2100 = 58,800,000
```

这一步是手算能对上的关键：**分母不需要先算加权均值再平方，直接用 2·ΣPa·ΣP**。

分子逐对列出（`i<j` 的 15 对，每对贡献 `2·P_i·P_j·|a_i−a_j|`）：

| 对 | P_i·P_j | \|a_i−a_j\| | 单侧贡献 | 记入分子（×2） |
|---|---|---|---|---|
| Z1–Z2 | 20,000 | 2 | 40,000 | 80,000 |
| Z1–Z3 | 30,000 | 4 | 120,000 | 240,000 |
| Z1–Z4 | 40,000 | 6 | 240,000 | 480,000 |
| Z1–Z5 | 50,000 | 8 | 400,000 | 800,000 |
| Z1–Z6 | 60,000 | 10 | 600,000 | 1,200,000 |
| Z2–Z3 | 60,000 | 2 | 120,000 | 240,000 |
| Z2–Z4 | 80,000 | 4 | 320,000 | 640,000 |
| Z2–Z5 | 100,000 | 6 | 600,000 | 1,200,000 |
| Z2–Z6 | 120,000 | 8 | 960,000 | 1,920,000 |
| Z3–Z4 | 120,000 | 2 | 240,000 | 480,000 |
| Z3–Z5 | 150,000 | 4 | 600,000 | 1,200,000 |
| Z3–Z6 | 180,000 | 6 | 1,080,000 | 2,160,000 |
| Z4–Z5 | 200,000 | 2 | 400,000 | 800,000 |
| Z4–Z6 | 240,000 | 4 | 960,000 | 1,920,000 |
| Z5–Z6 | 300,000 | 2 | 600,000 | 1,200,000 |
| **合计** | | | **7,280,000** | **14,560,000** |

```
G = 14,560,000 / 58,800,000 = 0.247619  （= 26/105）
```

> 首次手算时漏了 Z3–Z6 那一对（1,080,000），得到 12,400,000 与 0.210884。
> 脚本跑出 0.247619 才发现。**这就是人工算例的作用：手算与脚本互相校验，谁错谁改。**

## 4. P10 与最低 20% 群体

**P10（人口加权第 10 百分位）**：按 `a_i` 升序累计人口份额。

```
Z1: 100/2100 = 4.76%     ← 累计 4.76%，未到 10%
Z2: +200/2100 = 14.29%   ← 累计 14.29%，跨过 10% → 取该单元的值
```

`P10 = 2`。

**最低 20% 群体**（按人口切，边界单元按比例分开）：

```
目标人口 = 20% × 2100 = 420 人
Z1 全取 100 人（a=0）              → 累计 100
Z2 全取 200 人（a=2）              → 累计 300
Z3 取 120 人（a=4）                → 累计 420 ✔（Z3 只取了 120/300，是「部分单元」）
加权可达性 = 100×0 + 200×2 + 120×4 = 880
群体加权均值 = 880 / 420 = 2.095238
```

**四项必须并列报告**（只报 Gini 视为未完成，§4.3）：

| 指标 | 值 |
|---|---|
| 人口加权均值 | 6.666667 |
| Gini | 0.247619 |
| P10 | 2.000000 |
| 最低 20% 群体 | 420 人（占 20.0000%），加权均值 2.095238 |

## 6. 两个验收算例（计划 §5.2 明写要过的两例）

### 算例一：均匀供给 —— 每处都是 12 桩/千人

| 检查项 | 期望值 | 为什么 |
|---|---|---|
| 加权均值 | 12 | 全部相同 |
| Gini | **0** | 所有成对差为 0，分子为 0 |
| Lorenz | 与对角线重合 | 累计可达性份额 = 累计人口份额 |
| P10 | 12 | 任何分位都是 12 |
| 最低 20% 群体均值 | 12 | 同上 |
| 相对低可达单元数 | **0** | 判定用「严格小于分位数」；若用「≤」，6 个单元会全被判为低可达 |

最后一行是这一例真正的价值：**它能把「均匀供给下全员低可达」这个错误实现抓出来**。

### 算例二：单区供给 —— 只有 Z1 有 60 桩/千人

```
ΣPa = 60 × 100 = 6000
分子 = 2 × Σ_{j≠1} (100 × P_j × 60) = 2 × 6000 × 2000 = 24,000,000
分母 = 2 × 6000 × 2100 = 25,200,000
G = 24,000,000 / 25,200,000 = 20/21 = 0.952381
```

| 检查项 | 期望值 | 说明 |
|---|---|---|
| 加权均值 | 6000/2100 = 2.857143 | 只有 Z1 那 100 人享受到了供给 |
| Gini | 0.952381 | 极度不均，但**不是 1** —— 因为占了 100 人也算「有人拿到了」 |
| P10 | 0 | 底部 10% 的人口完全没有供给 |
| 最低 20% 群体均值 | 0 | 420 人全部落在 `a=0` 的单元 |
| 无观测覆盖 | 5 个单元 / 2000 人 | Z2—Z6 |
| 相对低可达 | **0 个单元** | 阈值 = 0，严格小于 0 不存在 |

这一例暴露一个必须写进口径卡的坑：**「无观测覆盖」可以不进「相对低可达」**。所以两个定义不能互相替代，并集才是「受影响人口」。

## 7. 三种低可达判定方式的差别（必须在口径卡里选定一种）

| 方式 | 阈值 | 判据 | 混合算例判出 | 适用 |
|---|---|---|---|---|
| `below_quantile`（本项目默认） | 单元分位数 2.0 | `a_i < 阈值` | 1 个单元（Z1） | 均匀供给下不误标，推荐 |
| `at_quantile` | 单元分位数 2.0 | `a_i ≤ 阈值` | 2 个单元（Z1、Z2） | 会把恰好等于阈值的单元算进来 |
| `rank` | 第 `ceil(20%·n)` 小 = 2.0 | `a_i ≤ 阈值` | 2 个单元（Z1、Z2） | 小样本、大量并列零值时更稳 |

**并集去重**（`at_quantile` 下）：无观测覆盖 1 个 + 相对低可达 2 个 = 3，去重后 **2 个**，省下 1 个。两类相加会把 Z1 数两次。

## 8. 一条结构性不变量（值得写进方法段）

**无观测覆盖 ⟹ `a_i = 0`**。反过来不一定成立（`a_i = 0` 只可能来自无站，但在并集里还要看阈值）。

推论：当零值单元占比**超过** 20% 时，「严格小于分位数」会把阈值压到 0，于是相对低可达判出空集，而零值单元全在无观测覆盖里。**这时并集是唯一正确的口径**，单独报任何一类都会严重低估受影响人口。真实数据里低可达单元大概率不会这么少，所以这条要在 11/12 拿到 `accessibility` 后第一时间验一遍。

## 10. 11/08 口径说明卡要拍板的六件事

1. 「相对低可达」用单元分位数还是人口分位数（本算例按单元）。
2. 判据用严格小于还是含等号（本项目默认严格小于）。
3. 「最低 20% 群体」按人口切（可切分单元）还是按整单元计入（本项目按人口切）。
4. 并集去重后，两类各自的人数是否仍要并列报告（建议报，评分要看两类）。
5. 10% / 30% 只作对照、不进正文结论。
6. 人口为零的单元：剔出统计、保留在表里、单独计数并说明。
