## 2 口径

1. **研究域** `in_study == True`，997 个格网；**统计域**再取 `pop > 0`，951 个。人口为 0 的 46 个格网只计数，不进加权统计、不进分位数。
2. **单位** `A_i` 为桩/人；对外一律报「每千人桩数」= `A_i × 1000`。
3. **无观测覆盖** `n_stations_in_radius == 0`。该条件与 `A_i == 0` 在全部 6,381 行上等价，脚本硬校验，不等价即报错。
4. **相对低可达** `A_i` **严格小于**线性插值 20% 分位（`quantile_strict`）。不用含等号：均匀供给下含等号会把全部单元判成荒漠（`tests_equity.py::test_uniform_supply`）。
5. **受影响人口** 两类并集，按 `cell_id` 去重；两类各自的人数与单元数并列报告，重叠单独计数。
6. **敏感性重合度** 在**受影响并集**上计算：1 km 下低可达判空（§4 注），只有并集与其他半径可比。

## 5 稳健性实测

主结果依赖三个不在 B 手里的假设。与其请 A 确认口径，不如把假设扰动一遍，看结论会不会翻。生成脚本 `src/08_robustness.py`，可重跑。

| 扰动 | Gini（3 km） | 并集 格 / 人 | 占比 |
|---|---:|---|---:|
| 基线（无扰动） | 0.2936 | 190 / 2,102,601 | 14.28% |
| T1 研究区近似（剔 48 格） | 0.2937 | 182 / 2,123,261 | 14.64% |
| T2 坐标整体偏移 500 m | 0.3129 | 190 / 2,159,642 | 14.67% |
| T3 供给口径（7% 站 ±30%） | 0.2933 | 190 / 2,135,497 | 14.51% |

**T1 研究区近似**：剔掉「研究区内、距 TAZ 质心 > 1.4 km」的孔洞填充格网。这部分共 48 格、216,118 人（占研究区 1.47%）、21 站 / 216 桩，由 `binary_fill_holes` 补入、不在缓冲并集本身。剔除后有效格 951 → 908，Gini 变化 +0.0001，受影响人口占比 +0.36 个百分点。

**T2 坐标偏移**：全部站点整体平移 (433, 250) m（模 500 m），作为 GCJ-02 偏移的粗略上界代理——不是真实变换，只用来判断量级。主半径 Gini +0.019、占比 +0.39 个百分点。**1 km 明显更敏感**：Gini 0.5756 → 0.6053，零覆盖格 229 → 238，并集占比 10.26% → 12.21%。方向不变，但 1 km 那一组不宜作为硬结论使用。

**T3 供给口径**：随机 7% 站点，桩数乘 U(0.7, 1.3) 与 U(0.5, 1.5)，种子 7 / 11。总桩数在 24,769–24,813 之间波动，Gini 0.2932–0.2936，并集格数恒为 190，占比 14.47%–14.51%。Gini 对整体尺度不敏感，局部扰动被 1,682 个站点平均掉。

**小结**：三个假设的最坏扰动都没有改变「约 190 格 / 210–216 万人、Gini 0.29–0.31」的量级与方向。唯一需要标注的是 1 km 对坐标误差敏感。
